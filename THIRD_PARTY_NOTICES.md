# Upstream provenance and third-party notices

This project targets behavior of [FDH2/UxPlay](https://github.com/FDH2/UxPlay) at commit `517cbb1240d9b9f69330c55b957cdd52b4175b2a` (2026-09-17). On 2026-10-05 the reference checkout was fetched again and the differences to `3dbf7ceee65932154e85a2f83963d53520a799fa` were reviewed file by file; the verdict per upstream file is recorded in `docs/ARCHITECTURE.md` section 0. The local research checkout is under `upstream/UxPlay`, is ignored by the root repository, and is not linked into the Rust product.

The Rust migration is licensed under GPL-3.0-or-later. UxPlay incorporates sources with GPL, LGPL and MIT notices. This document does not relicense those components. Retain original copyright and license notices whenever translating or incorporating their implementation/data. Before each such migration, record the exact source files and notices here.

The FairPlay framing constants are translated from `upstream/UxPlay/lib/fairplay_playfair.c`; PlayFair table assets and the FairPlay transforms are translated from `upstream/UxPlay/lib/playfair/` (`omg_hax.{c,h}`, `modified_md5.c`, `playfair.c`, `sap_hash.c`, `hand_garble.c`). `fairplay_playfair.c` carries the LGPL-2.1-or-later notice of Juho Vähä-Herttua; the `playfair/` files carry no per-file header, so their Rust translations (`playfair.rs`, `playfair_tables.rs`, `playfair/hand_garble_generated.rs`) use the same LGPL-2.1-or-later notice. These files are retained locally for provenance and each Rust translation keeps the applicable upstream SPDX notice. Test vectors constructed in this project are synthetic and are not device captures.

No third-party documentation is redistributed in this repository. The upstream projects this crate was written against are cited by URL in the paragraphs below; being cited is not a claim of tested integration and does not change any upstream licence.

The plist layer (`crates/rust-airplay/src/plist.rs`) depends on the [`plist`](https://crates.io/crates/plist) crate 1.8.0 (MIT), which reads and writes the binary and XML property-list formats that upstream gets from libplist. `Cargo.lock` also pins its transitive dependencies (`quick-xml`, `indexmap`, `hashbrown`, `time`, `base64ct`, ...). Version, licence and MSRV details for this stack are in `Cargo.lock` and `docs/BUILD.md`. The fixtures in `crates/rust-airplay/tests/fixtures/` are generated by the CPython standard library `plistlib` module through `tools/plist_fixtures.py`; they are synthetic test data, and no CPython or plistlib code is linked into the product.

The network control service (`crates/rust-airplay/src/server/`) depends on [`tokio`](https://crates.io/crates/tokio) 1.53.1 (MIT) with the `rt-multi-thread`, `net`, `time`, `sync`, `io-util` and `macros` features, the async runtime `Cargo.lock` pins together with `bytes`, `mio`, `pin-project-lite`, `socket2`, `tokio-macros` and `windows-sys`. The choice, its alternatives and the MSRV evidence are in `docs/ARCHITECTURE.md`.

The pairing service (`crates/rust-airplay/src/server/pairing.rs`) draws its random values — the one-time PIN, the SRP salt and private value, and the X25519 key pair of `/pair-verify` — from [`getrandom`](https://crates.io/crates/getrandom) 0.2.15 (MIT OR Apache-2.0). It was already pinned as a transitive dependency of `rand_core` before it was declared directly, so the dependency set of the product is unchanged; the decision and the identity rules around it are in `docs/ARCHITECTURE.md`.

The differential oracle under `tools/oracle/` is a **test tool**: it compiles the upstream sources named above (`srp.c`, `crypto.c`, `pairing.c`, `fairplay_playfair.c`, `playfair/*`, `logger.c`, `compat.c`, `utils.c`) into one program that prints vectors, and the ignored Rust tests compare them with this crate. It is built from the local `upstream/UxPlay` checkout, it is never linked into the Rust product, its binary is ignored by Git, and it inherits the upstream notices listed above — including the MIT notice of Tom Cocagne's SRP implementation, which `srp.c` carries. `tools/oracle/README.md` records how to build and run it and what each vector checks.

Discovery (`crates/rust-airplay/src/discovery.rs`) depends on [`mdns-sd`](https://crates.io/crates/mdns-sd) 0.21.5 (Apache-2.0 OR MIT), a multicast-DNS responder written in Rust. `Cargo.lock` also pins its transitive dependencies (`if-addrs`, `socket-pktinfo`, `socket2`, `flume`, `log`, `parking_lot`/`lock_api`, `scopeguard`, `spin`, ...). The choice and the alternatives it replaced — Apple's Bonjour through `dns_sd.h`, or Avahi through its client library — are recorded in `docs/ARCHITECTURE.md`. The record contents this module advertises are transcribed from upstream `lib/dns_sd/dns_sd.c` and `lib/dnssdint.h`, which is what makes a stock client accept the receiver.

The renderer boundary (`crates/rust-airplay/src/render.rs`) has **no dependencies**: it is the trait a backend implements, the frame and configuration types a session hands across it, and a renderer that accepts everything and plays nothing (`NullRenderer`). It is a member of the default workspace, so the gates that run on a machine without a media library cover it.

The GStreamer backend (`crates/rust-airplay-gstreamer`) is a workspace of its own and is **not** built by the default gates. Its video path runs `gst-launch-1.0` as a subprocess and writes frames to its standard input, so GStreamer is a run-time dependency there; its audio path links `libgstreamer` through the `gstreamer` crate, which is a build-time dependency on the GStreamer development files. Either way it is a dependency of that crate only: a machine without GStreamer still builds and passes every gate in the default workspace. `docs/ARCHITECTURE.md` records the decision and `crates/rust-airplay-gstreamer/README.md` the alternatives it rejected. Adding a Rust dependency to that crate later means recording it here first, as the rules at the top of this file require.

To obtain the reference checkout on a new machine:

```powershell
git clone https://github.com/FDH2/UxPlay.git upstream/UxPlay
git -C upstream/UxPlay checkout --detach 517cbb1240d9b9f69330c55b957cdd52b4175b2a
git -C upstream/UxPlay rev-parse HEAD
```
